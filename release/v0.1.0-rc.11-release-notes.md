## Accepted behavior

- Exact replay hashes run first. Active persisted Session lineage can rebuild a
  serializer-drift checkpoint for provider requests and compaction preflight.
  Valid legacy lineage records can use this fallback. The fallback does not
  authenticate manually rewritten history when old hashes cannot be reproduced.
- Timeline cards use the current Session compaction leaf and fall back to the
  event entry. Native and unsupported leaves do not create remote cards.
- Route recognition keeps the official OpenAI, Azure, and Codex rules. It also
  permits any configured HTTPS base URL with the exact `openai-responses` API and
  a case-insensitive `gpt-5` or `gpt-6` model substring. Recognition permits an
  attempt. It does not prove transport compatibility. Query-based routing is
  unsupported because the adapter and endpoint identity discard queries and
  fragments.
