# @hypercarrier/pi-openai-blackmagic-compact v0.1.0-rc.10

This release candidate adds conversation-scoped replay. It preserves current
request instructions and tools, supports eligible same-route model switches,
and blocks malformed persisted checkpoints before provider egress.

The owner requested publication on 2026-09-15. The proposed version is
`0.1.0-rc.10` on `next`; `latest` remains `0.1.0-rc.9`.

Publication requires human review, exact-source package/install checks,
authenticated replay evidence, privacy checks, and a nonce-correlated workflow
dry run. Pending or failed gates hold publication. Corrections after publication
require a higher version; existing tags and package bytes must not change.

## Known limits

- A UI-only tail can report remote readiness while Pi declines native `/compact`
  work. This is a known readiness false positive.
- Early authenticated live runs observed HTTP 400 responses. Authenticated
  remote acceptance and cross-model acceptance remain unverified.
- Earlier runs observed eight HTTP responses but did not fully control WebSocket
  transport. Total egress remains unverified.

Local property, integration, package, and packing checks pass. No live provider
acceptance is claimed by those checks.
